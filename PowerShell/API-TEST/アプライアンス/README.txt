================================================================================
アプライアンス管理サービス API テストスクリプト
================================================================================

概要
----
このスクリプトは、アプライアンス管理サービスのAPIを仕様書記載順に順次呼び出し、
各APIの動作確認を行うためのPowerShellスクリプトです。

ファイル名
----------
appliance-api-test.ps1

必要な環境
----------
- PowerShell 5.1 以上
- インターネット接続
- 有効なBearerトークン
- アプライアンス管理サービスへのアクセス権限

事前準備
--------
スクリプト実行前に以下の設定が必要です：

1. 管理タグの設定
   アプライアンス管理 > 管理タグ一覧設定で以下のタグを事前に登録してください：
   - tag1
   - tag2
   
   ※これらのタグは「全般-表示名・タグ更新」処理で使用されます

パラメータ
----------
[必須]
-HostName    : インターフェイスホスト名（例: "your-host"）
-Token       : HTTP ヘッダに付与するBearerトークン

[オプション]
-DryRun      : 破壊的操作（DELETE等）をスキップします。POST/PUT は送信前に内容を表示して確認用に最小限だけ実行
-production  : 本番環境への接続（https://{HostName}.ids.soliton-ods.jp）
               未指定時は開発環境（https://{HostName}.ids-dev.solitonsys.jp）に接続
-HardwareId  : 対象アプライアンスを明示的に指定（未指定時は検索結果の先頭を使用）
-OutputDir   : ダウンロードファイルの出力先ディレクトリ（既定: "./output"）
-y           : Enter待ちをスキップして連続実行します

使用方法
--------
開発環境での基本実行:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token"

本番環境での実行:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -production

DryRunモードで実行（開発環境）:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -DryRun

DryRunモードで実行（本番環境）:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -production -DryRun

特定のアプライアンスを指定:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -HardwareId "12345"

出力先を指定:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -OutputDir "C:\temp"

連続実行（Enter待ちをスキップ）:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -y

本番環境でDryRunモードで連続実行:
PS> .\appliance-api-test.ps1 -HostName "your-host" -Token "your-bearer-token" -production -DryRun -y

実行される処理
--------------
1. アプライアンス検索
   - 全アプライアンスを検索し、対象となるhardwareIdを決定

2. 全般-表示名・タグ更新
   - アプライアンスの表示名とタグを更新

3. 管理-バックアップ開始
   - バックアップ処理を開始（タイムスタンプ付きの名前で作成）

4. 管理-バックアップ一覧取得
   - 既存のバックアップ一覧を取得

5. 管理-バックアップダウンロード
   - 最古のバックアップファイルをダウンロード

6. 管理-バックアップ削除
   - ダウンロードしたバックアップを削除

7. 管理-停止・再起動
   - アプライアンスの再起動を実行（60秒待機）

8. 管理-ファーム一覧取得
   - 利用可能なファームウェア一覧を取得

9. 管理-ファームアップデート
   - 利用可能な最新ファームウェアでアップデート実行（60秒待機）

10. ログ-ログエクスポート
    - SYSLOGタイプのログをエクスポートして保存

11. アプライアンス削除
    - 対象アプライアンスを削除

出力ファイル
------------
- ./output/backup_[タイムスタンプ].tgz : バックアップファイル
- ./output/logs_[HardwareId]_SYSLOG.log : ログファイル

注意事項
--------
1. **破壊的操作を含みます**
   - アプライアンスの削除、再起動、ファームアップデートが含まれます
   - 本番環境での実行前に必ずDryRunモードでテストしてください

2. **対象アプライアンスの自動選択**
   - HardwareIdパラメータを指定しない場合、検索結果の先頭アプライアンスが自動選択されます
   - 以下の処理が選択されたアプライアンスに対して実行されます：
     * 全般-表示名・タグ更新
     * バックアップ開始/一覧取得/ダウンロード/削除
     * 停止・再起動
     * ファーム一覧取得/ファームアップデート
     * ログエクスポート
     * アプライアンス削除
   - 意図しないアプライアンスが対象となる可能性があるため、重要な環境では
     必ずHardwareIdを明示的に指定することを推奨します

3. **実行時間**
   - 処理には時間がかかります（待機時間含む）
   - 各処理後にEnterキー入力待ちがあります（-y スイッチで省略可能）

3. **エラー処理**
   - エラー発生時は詳細情報が表示されます
   - HTTP 406エラー等の場合、レスポンスヘッダーも表示されます

4. **権限**
   - 提供されたBearerトークンに適切な権限が必要です
   - アプライアンス管理のフル権限が必要な処理が含まれます

5. **ネットワーク**
   - 開発環境: https://{HostName}.ids-dev.solitonsys.jp へのアクセスが必要です
   - 本番環境: https://{HostName}.ids.soliton-ods.jp へのアクセスが必要です（-production 指定時）

6. **環境指定**
   - -production パラメータを指定しない場合、開発環境に接続されます
   - 本番環境での実行時は必ず -production パラメータを指定してください

トラブルシューティング
----------------------
- URI構築エラー: HostNameの形式を確認してください
- 認証エラー: Bearerトークンの有効性を確認してください  
- 406エラー: APIの仕様変更やヘッダー設定の問題の可能性があります
- タイムアウト: ネットワーク接続や待機時間の調整が必要な場合があります

更新履歴
--------
- -production パラメータを追加（開発環境/本番環境の切り替え機能）
- DryRunモードの動作を改善（POST/PUT は送信前に内容を表示して確認用に最小限だけ実行）
- 基本設定更新処理を削除
- バックアップ選定を最新→最古に変更
- 各処理後にEnterキー入力待ちを追加
- エラーハンドリングを強化
